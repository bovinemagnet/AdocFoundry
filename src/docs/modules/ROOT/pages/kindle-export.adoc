= Exporting to Kindle
Paul Snow
:revnumber: 0.0.0
:description: Exporting a page or a whole Antora component to a Kindle book (AZW3 or KFX): what it contains, how to export, settings, warnings and what the reader lays out for itself.

AdocFoundry exports a page, or a whole component version, as a Kindle book in AZW3 (KF8) or KFX (KF10).
AdocFoundry writes the book itself, in Rust, from one book representation.
It needs no Calibre, KindleGen, Kindle Previewer, other program or network access, and one format is never written in place of the other.
For the other formats, see xref:pdf-export.adoc[Exporting to PDF] and xref:word-export.adoc[Exporting to Word].

IMPORTANT: These are files to read and sideload on a Kindle or in a Kindle app.
They are not Kindle Direct Publishing manuscripts, which KDP takes as xref:epub-export.adoc[EPUB], DOCX or KPF, and KPF is a different format from KFX.
Neither format has yet been checked on a Kindle device.
AZW3 books have been read correctly in Calibre.
KFX is untested: no reader outside AdocFoundry's own tests has opened a KFX book yet, so choose AZW3 unless you are prepared to check the book yourself.
The manual checks are in `docs/qa/kindle.md` in the repository.

WARNING: KFX export is untested.

== Formats

[cols="1,4"]
|===
|Format |Use

|AZW3 (KF8)
|Read by most Kindles and Kindle apps.

|KFX (KF10)
|Current Kindles' own format.
Untested: see the warning above.
|===

The format is the one given to the export, else the output's extension, else `[kindle] format`, which is AZW3 by default.
A format and an output whose extension disagree are refused.

== What it makes

A book holds the same pages as the PDF and Word exports, in navigation order, each once.
The start page is a preface, and a part is a chapter of its own.

* The table of contents is nested.
* A cross reference between pages of the book is a link inside the book.
* Headings, lists, code, tables and footnotes stay text.
* Pictures and diagrams are embedded.
* STEM formulas are embedded as pictures, with their source as the alternative text.
Without the engine's `typst` feature, a formula is its source as text.
* The cover is embedded: the `front-cover-image` attribute, else `[kindle] cover`, or a profile's `cover`.
* A remote image is linked and never fetched.
* Audio, video and a table inside a table are kept readable, with a warning at their line.

The reader owns fonts, page layout, page numbers and themes, so a book has no running headers or footers.

== Exporting

=== In the application

Choose one of these from the Export menu.
Each is also in the command palette.

* Export Page to Kindle… (`export.kindle_page`) exports the active page.
* Export Component to Kindle… (`export.kindle_component`) exports the component version that holds the active page.
* Export Kindle Profile… (`export.kindle_profile`) exports a named Kindle publication; see <<settings>>.

The first two each offer a format picker, with AZW3 (KF8) and KFX (KF10) and the `[kindle] format` default first, and then ask where to save the file.
A profile uses its own format.
When the export finishes, a notification reports it as other exports do, for example "Exported guide.kfx (8 AsciiDoc pages)", with any warnings.
Nothing is previewed or opened.

=== From the command line and MCP

`adocfoundry-cli kindle` exports from a shell or a build script; see xref:command-line.adoc#kindle[Command line].
The `export_kindle` tool of the MCP server does the same for an agent; see xref:mcp-server.adoc[MCP server].

=== What is exported

A page exports as an article.
A component version exports as a book from the navigation, each page once.
Unsaved edits are exported, because the export reads open buffers.
The export selects the same pages as the PDF and Word exports.

A page whose header says `:export-read-only:` is refused for Kindle, since a Kindle book carries no restriction; see xref:read-only-exports.adoc[Read-only exports].

[#settings]
== Settings

The `[kindle]` table sets the format and the book's metadata, and `[kindle.profiles.<name>]` saves Kindle publications under a name.
See xref:settings.adoc#kindle-settings[Kindle export settings] for the keys.
Nothing is read from `[pdf]` or `[docx]`.

== Warnings

A problem is reported as a warning that names the file and line, in the page or the partial it comes from.
Warnings cover these cases.

* A missing image.
* A diagram that nothing can render.
* Audio, video or a table inside a table, which is kept readable.
* A reference that leads out of the book, which is a link to the site when the site's address is known, and otherwise text.

The book is still written.
On the command line, `--fail-on` makes the command fail when a warning is reported.

== Safety

* The book is written to a temporary file beside the output and renamed over it only when it is complete.
A failed or timed-out export leaves any existing file untouched.
* An output that is a link, a folder or not a `.azw3` or `.kfx` file is refused.
* Profiles and the MCP tool write only inside the workspace.

== The reader lays out the pages

AdocFoundry writes the content and the Kindle decides the fonts, the page layout and the page numbers.
Page breaks and page counts therefore differ from the PDF's and between devices.
