= Keyboard shortcuts
Paul Snow
:revnumber: 0.0.0
:description: Every default key binding in AdocFoundry.

Bindings come from the engine's command definitions, so the command palette and this table agree.
In the engine, `cmd` means the platform's primary modifier: Command on macOS and Control on Linux and Windows.
Two bindings, Go Back and Go Forward, use Control on every platform.

Fifteen commands have no default binding and are available from the palette: Re-index Workspace (`workspace.reindex`), Reload Settings (`settings.reload`), Refresh Git Status (`git.refresh`), Revert Change (`git.revert_hunk`), Show Changes (`git.show_changes`), Toggle Blame (`git.show_blame`), Open in Another Version (`navigate.open_in_version`), Open on Remote (`navigate.open_on_remote`), Copy Remote Link (`navigate.copy_remote_link`), Stage (`git.stage`), Unstage (`git.unstage`), Stage All Changes (`git.stage_all_adoc`), Commit (`git.commit`), Push (`git.push`) and Save and Commit (`git.save_and_commit`).
Two export commands also have no default binding and are available from the palette: Export Page to PDF… (`export.pdf_page`) and Export Component to PDF… (`export.pdf_component`).
See xref:pdf-export.adoc[Exporting to PDF].
Two document commands also have no default binding and are available from the palette: Reload from Disk (`document.reload`) and Save, Overwriting the File on Disk (`document.overwrite`).
See xref:using-the-editor.adoc[Using the editor].
Three preview commands also have no default binding and are available from the palette: Detach Preview (`view.detach_preview`), Toggle Preview Scroll Sync (`view.toggle_scroll_sync`) and Pin Preview (`preview.pin`).
Toggle Preview is a chord: hold the modifier for kbd:[K] only, release it, then press kbd:[V] on its own.
See xref:preview.adoc[The preview].
Go to Location (`navigate.go_to`) and Reveal in Editor (`navigate.reveal`) take a position and are driven by clicks in the preview rather than bound to keys.
Apply Preview (`workspace.apply_preview`), Insert Text (`edit.insert_text`) and Replace Range (`edit.replace_range`) are driven by the user interface rather than bound to keys.

Undo, redo, go to definition, follow link and peek include are bound in the editor's key context after the editor widget's own bindings, so they take precedence and go through the engine.

[[visual-editor]]
== Visual editor

These bindings apply while the visual editor has focus.
Undo and redo are the commands above, and are shared with the source editor.
Bold, Italic and Code, with the same keys, also work in the source editor; see xref:using-the-editor.adoc#formatting-text[Formatting text in the source editor].
Highlight (`edit.toggle_highlight`) has no key in either editor and is in the palette.
See xref:visual-editing.adoc[Visual editing].

Some visual commands have no default binding and are available from the palette or the toolbar: Highlight (`edit.toggle_highlight`), Set Block Type (`edit.set_block_type`), Remove Link (`edit.remove_link`), Check or Uncheck (`edit.toggle_checked`), Insert Image (`edit.insert_image`), Edit Image (`edit.edit_image`), Insert Table (`edit.insert_table`), Insert Table Row, Delete Table Row, Insert Table Column and Delete Table Column (`edit.insert_table_row`, `edit.delete_table_row`, `edit.insert_table_column`, `edit.delete_table_column`), Insert Code Block (`edit.insert_code_block`) and Insert Admonition (`edit.insert_admonition`).
Type (`visual.insert_text`) and Insert Block (`visual.insert_block`) are driven by typing and by Enter rather than bound to keys.
Highlight has no binding because Cmd-Shift-H and Ctrl-Shift-H are Replace in Workspace.

The Source, Visual and Split commands are chords like Toggle Preview: hold the modifier for kbd:[K] only, release it, then press the letter on its own.

NOTE: User-defined key bindings are not implemented.
