= Keyboard shortcuts
Paul Snow
:revnumber: 0.0.0
:description: Every default key binding in AdocFoundry.

Bindings come from the engine's command definitions, so the command palette and this table agree.
In the engine, `cmd` means the platform's primary modifier: Command on macOS and Control on Linux and Windows.
Two bindings, Go Back and Go Forward, use Control on every platform.

Two commands have no default binding and are available from the palette: Re-index Workspace (`workspace.reindex`) and Reload Settings (`settings.reload`).
Three preview commands also have no default binding and are available from the palette: Detach Preview (`view.detach_preview`), Toggle Preview Scroll Sync (`view.toggle_scroll_sync`) and Pin Preview (`preview.pin`).
Toggle Preview is a chord: hold the modifier for kbd:[K] only, release it, then press kbd:[V] on its own.
See xref:preview.adoc[The preview].
Go to Location (`navigate.go_to`) and Reveal in Editor (`navigate.reveal`) take a position and are driven by clicks in the preview rather than bound to keys.
Apply Preview (`workspace.apply_preview`), Insert Text (`edit.insert_text`) and Replace Range (`edit.replace_range`) are driven by the user interface rather than bound to keys.

Undo, redo, go to definition, follow link and peek include are bound in the editor's key context after the editor widget's own bindings, so they take precedence and go through the engine.

NOTE: User-defined key bindings are not implemented.
