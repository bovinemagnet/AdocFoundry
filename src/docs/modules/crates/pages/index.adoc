= Crates
Paul Snow
:revnumber: 0.0.0
:description: One page for each crate in the AdocFoundry workspace, grouped by layer, saying what it does and how to use it.

AdocFoundry is a workspace of 21 crates arranged as a ladder of layers.
A crate may depend only on crates in the layers below it, apart from the same-layer pairs the layering check allows.
Each page in this module covers one crate: what it does, how to use it, where it sits, how to test it and where the main documentation says more.
